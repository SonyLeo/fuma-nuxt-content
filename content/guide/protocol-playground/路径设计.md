这个页面用于验证当前项目的 route policy 是否对齐 Fumadocs 的核心做法：

- frontmatter `slug` 可以直接写非 ASCII 文本
- 最终 route 会按 segment 做 URI 编码
- 内容查询仍然按 source path 语义工作，而不是按编码后的 route path

## 预期

- 当前 source file 名称仍然是 `路径设计.md`
- 最终访问路径应归一化到 `/guide/protocol-playground/%E7%9C%9F%E5%AE%9E%20%E8%B7%AF%E5%BE%84`
- breadcrumb、pager、sidebar 都只消费最终 route path
- source path 仍然保持未编码语义，继续服务于内容查询和 `pagesIndex` 匹配
